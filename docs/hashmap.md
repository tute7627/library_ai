# cp::hashmap<Key, T>

整数キー向けのハッシュマップ。`std::unordered_map<int, T>` や
`std::unordered_map<long long, T>` の、以下のAPIを使うコードを置き換えられる。
共通ヘッダ `library/template.hpp` を先に読み込んで使用する。

```cpp
// Source: https://github.com/tute7627/library_ai/blob/main/library/template.hpp
// Source: https://github.com/tute7627/library_ai/blob/main/library/hashmap.hpp
#include "library/template.hpp"
#include "library/hashmap.hpp"

int main() {
    cp::hashmap<long long, int> count;
    count.reserve(200000);
    ++count[42];
    count.insert({-7, 3});

    if (auto it = count.find(42); it != count.end()) {
        ++it->second;
    }
    for (auto& [key, value] : count) {
        (void)key;
        value += 1;
    }
    count.erase(-7);
    count.dump(std::cerr) << '\n';
    std::cerr << count << '\n';
}
```

2つの出力はいずれも `{42: 3}`。要素数の目安が分かる場合は `reserve` を推奨する。

## 前提と計算量の表記

- `Key` はboolを除く64bit以下の整数型。主な対象は `int` と `long long`。
- `T` はムーブ構築またはコピー構築可能な型。コピーや `operator[]` などには、各APIに記載する追加条件がある。
- C++17以上かつ `<bits/stdc++.h>` を使える環境が必要。
- カスタムハッシュ・比較関数・アロケータ、ノード操作、バケット単位のAPI、ヒント付き挿入、最大使用率の変更には対応しない。

以下では `N = size()`、`C = bucket_count()`、`K` は一括挿入する要素数、
`C'` は操作後の容量とする。計算量の式が0になる空ケースも `O(1)` として読む。
値の構築・コピー・ムーブ・破棄のコストは1回あたり `O(1)` としている。

「期待」はハッシュが十分に分散する場合、「償却」は一連の操作全体で平均した計算量。
ランダムシードによる確率的な衝突対策を行うが、最悪計算量は保証しない。
検索は最悪 `O(C)`、衝突が集中する再構築は最悪 `O(C + C' + N²)` となり得る。

保持領域は `O(C)`。特記しないAPIの追加領域は `O(1)`、再構築時の追加領域は `O(C')`。
値自身が別途確保する領域は含めない。容量は0、または16以上の2のべき乗で、最大使用率は50%。
削除による自動縮小は行わない。
領域確保や値の構築・コピー・ムーブで生じた例外は呼び出し元へ伝わる。
確保上限や再構築失敗時の注意は `reserve`・`rehash` を参照。

## API概略

| API | 内容・戻り値 | 時間計算量 |
|---|---|---|
| 空構築・容量指定構築 | 空のマップを作る。固定シードも指定可能 | 容量0なら `O(1)`、確保時 `O(C')` |
| 初期化リスト構築 | 要素をまとめて挿入 | 期待 `O(K)` |
| コピー構築 | 要素・容量・シードをコピー | `O(C_other)` |
| ムーブ構築 | 所有領域を移し、移動元を空にする | `O(1)` |
| コピー代入 | コピー元の内容に置き換える | `O(C + C_other)` |
| ムーブ代入 | 旧要素を破棄して所有領域を移す | `O(C)` |
| デストラクタ | 全要素を破棄し領域を解放 | `O(C)` |
| `swap` | 領域・要素・シードを交換 | `O(1)` |
| `operator[]` | 未登録なら値初期化して挿入し、値への参照を返す | 期待償却 `O(1)` |
| `find` | 要素のイテレータ、未登録なら `end()` | 期待 `O(1)` |
| `count` / `contains` | 登録件数（0か1） / 存在するか | 期待 `O(1)` |
| 単一要素の `insert` | `{iterator, 挿入できたか}`。既存値は変更しない | 期待償却 `O(1)` |
| 範囲・初期化リストの `insert` | 複数要素を挿入 | 期待償却 `O(K)` |
| `try_emplace` | 未登録なら引数から値を構築。戻り値は単一要素の `insert` と同じ | 期待償却 `O(1)` |
| `erase(key)` | 削除件数（0か1） | 期待償却 `O(1)`、最悪 `O(C)` |
| `erase(iterator)` | 削除した要素の次のイテレータ | `O(1 + D + W)`、最悪 `O(C)`（下記参照） |
| `begin` / `cbegin` | 最初の要素、空なら終端 | 最悪 `O(1 + C/64)` |
| `end` / `cend` | 終端イテレータ | `O(1)` |
| 範囲for・全走査 | 全要素を走査 | `O(N + C/64)` |
| `at` | 値への参照。未登録なら例外 | 期待 `O(1)` |
| `size` / `empty` | 要素数 / 空判定 | `O(1)` |
| `clear` | 確保領域を残して全削除 | `O(C)` |
| `reserve(n)` | n要素分の容量を確保 | 拡張時は期待 `O(C + C')`、拡張なしは `O(log(n + 1))` |
| `rehash(n)` | nスロット以上に再構築。縮小も可能 | 期待 `O(C + C')` |
| `bucket_count` / `load_factor` / `max_load_factor` | 容量 / 使用率 / 最大使用率 | `O(1)` |
| `hash_seed` | 現在の64bitシード | `O(1)` |
| `dump` / `operator<<` | `{key: value, ...}` を出力 | `O(N + C/64 + L)`（Lは出力処理のコスト） |

`C_other` はコピー元の容量。`D` はその削除で回収する削除跡の数、
`W` は次の要素までに調べる64スロット単位の管理領域の数。
挿入の償却計算量には、拡張・削除跡の整理による再構築を含む。
単一挿入でも再構築が発生した回は期待 `O(C + C')`、一括挿入では期待 `O(K + C + C')` かかる。

## API詳述

### 公開型

| 型名 | 定義・用途 |
|---|---|
| `key_type` / `mapped_type` | `Key` / `T` |
| `value_type` | `std::pair<const Key, T>` |
| `size_type` / `difference_type` | `std::size_t` / `std::ptrdiff_t` |
| `reference` / `const_reference` | `value_type&` / `const value_type&` |
| `pointer` / `const_pointer` | `value_type*` / `const value_type*` |
| `iterator` / `const_iterator` | 変更可能 / 読み取り専用の前方イテレータ |

キーは変更できない。`iterator` を通した値の変更は可能。
`const_iterator` ではキー・値ともに変更できない。

### コンストラクタ

書式: `hashmap()`、`explicit hashmap(size_type buckets)`、
`hashmap(size_type buckets, std::uint64_t seed)`。

- **引数**: `buckets` は初期スロット数の下限で、省略時0。要素数の指定ではない。`seed` はハッシュシードで、0を含むすべての64bit値が有効。
- **戻り値**: なし。空のマップを構築する。
- **内容**: `buckets == 0` なら領域を確保しない。それ以外は16以上の2のべき乗へ切り上げる。シード省略時は同じ `Key, T` の組み合わせでプロセス内に一度生成する通常用シードを使う。明示指定時は乱数源を使わない。
- **計算量**: 容量0なら時間・領域 `O(1)`。確保時は時間・領域 `O(C')`。通常用シードの生成にかかる乱数源の処理時間は含めない。
- **補足**: `cp::hashmap<long long, int> m(0, 123456789ULL);` で固定シードを使える。同じ実装・シード・容量・操作列なら走査順序も再現できる。通常利用ではシードを省略する。

### 初期化リストによる構築

書式: `hashmap(std::initializer_list<value_type> values)`。

- **引数**: 挿入するキーと値の組の列 `values`。
- **戻り値**: なし。要素を挿入済みのマップを構築する。
- **内容**: リストの要素数分を `reserve` し、先頭から挿入する。同じキーが複数ある場合は最初の値を保持する。シードは通常用シード。値のコピー構築が必要。
- **計算量**: K要素に対して期待時間 `O(K)`、領域 `O(C') = O(K + 1)`。

### コピー構築

書式: `hashmap(const hashmap& other)`。

- **引数**: コピー元 `other`。
- **戻り値**: なし。独立したマップを構築する。
- **内容**: 要素・容量・シード・配置をコピーする。コピー元は変更しない。値のコピー構築が必要。
- **計算量**: コピー元の容量を `C_other` として、時間・領域ともに `O(C_other)`。

### ムーブ構築

書式: `hashmap(hashmap&& other) noexcept`。

- **引数**: 移動元 `other`。
- **戻り値**: なし。所有領域を受け取ったマップを構築する。
- **内容**: 個々の値をムーブせず、領域とシードを引き継ぐ。移動元は要素数・容量ともに0となり、同じシードのまま再利用できる。移動元のイテレータは移動先で取り直す。
- **計算量**: 時間・追加領域ともに `O(1)`。

### コピー代入・ムーブ代入

書式: `hashmap& operator=(const hashmap& other)`、
`hashmap& operator=(hashmap&& other) noexcept`。

- **引数**: コピー元または移動元 `other`。
- **戻り値**: 代入先自身への参照 `*this`。
- **内容**: 代入先の旧要素・領域を破棄し、要素・容量・シードを置き換える。コピー代入には値のコピー構築が必要。ムーブ代入後の移動元は要素数・容量ともに0となる。自己代入・自己ムーブ代入は何もしない。
- **計算量**: 代入前の容量をCとして、コピー代入は時間 `O(C + C_other)`、追加領域 `O(C_other)`。ムーブ代入は時間 `O(C)`、追加領域 `O(1)`。自己代入は `O(1)`。
- **無効化**: 自己代入を除き、代入先の旧要素への参照・ポインタ・イテレータはすべて無効。ムーブ元のイテレータは移動先で取り直す。

### デストラクタ

書式: `~hashmap()`。

- **引数・戻り値**: なし。
- **内容**: 全要素を破棄し、確保領域を解放する。
- **計算量**: 時間 `O(C)`、追加領域 `O(1)`。

### swap

書式: `void swap(hashmap& other) noexcept`、`void swap(hashmap& a, hashmap& b) noexcept`（非メンバ版）。

- **引数**: メンバ版は交換相手 `other`。非メンバ版は交換する2つのマップ `a, b`。
- **戻り値**: なし。
- **内容**: 要素・容量・シードを領域ごと交換する。個々の値をコピー・ムーブしない。非メンバ版は `using std::swap; swap(a, b);` で使用できる。交換前のイテレータは交換後のマップで取り直す。
- **計算量**: 時間・追加領域ともに `O(1)`。

### operator[]

書式: `mapped_type& operator[](key_type key)`。

- **引数**: 取得・挿入するキー `key`。
- **戻り値**: 対応する値への参照。
- **内容**: 登録済みなら既存値を返す。未登録なら値を値初期化して挿入する。整数の値は0になる。値がデフォルト構築可能であること。
- **計算量**: 期待償却 `O(1)`。再構築する回は期待 `O(C + C')`。
- **無効化**: 新規挿入に伴って再構築すると、既存要素への参照・ポインタ・イテレータはすべて無効。既存キーへのアクセスでは再構築しない。
- **注意**: `m[new_key] = m[old_key]` は、新規挿入の再構築で右辺の参照が無効になる場合がある。先に値を別変数へコピーするか、未登録キーへの挿入には `try_emplace(new_key, m.at(old_key))` を使う。

### find

書式: `iterator find(key_type key)`、`const_iterator find(key_type key) const`。

- **引数**: 検索するキー `key`。
- **戻り値**: 見つかればその要素のイテレータ、未登録なら `end()`。constなマップでは `const_iterator`。
- **内容**: マップを変更せずに検索する。終端イテレータを参照外ししてはいけない。
- **計算量**: 期待 `O(1)`、最悪 `O(C)`。

### count・contains

書式: `size_type count(key_type key) const`、`bool contains(key_type key) const`。

- **引数**: 検索するキー `key`。
- **戻り値**: `count` は登録済みなら1、未登録なら0。`contains` は登録済みならtrue、未登録ならfalse。
- **内容**: マップを変更せずに存在を確認する。`contains` もC++17から使用できる。
- **計算量**: いずれも期待 `O(1)`、最悪 `O(C)`。

### 単一要素のinsert

書式: `std::pair<iterator, bool> insert(const value_type& value)`、
`std::pair<iterator, bool> insert(value_type&& value)`。

- **引数**: 挿入するキーと値の組 `value`。`insert({key, value})` の形でも呼び出せる。値が該当する引数からコピーまたはムーブ構築可能であること。
- **戻り値**: 対応する要素のイテレータと、新規挿入できたかの組。
- **内容**: 未登録ならコピーまたはムーブして挿入する。登録済みなら既存値を変更せず、`second == false` を返す。この場合、右辺値で渡した値も消費しない。左辺値版には値のコピー構築が必要。
- **計算量**: 期待償却 `O(1)`。再構築する回は期待 `O(C + C')`。
- **無効化**: 新規挿入の再構築時は全要素への参照・ポインタ・イテレータが無効。それ以外では既存要素は無効にならない。

### 範囲・初期化リストのinsert

書式: `template<class InputIt> void insert(InputIt first, InputIt last)`、
`void insert(std::initializer_list<value_type> values)`。

- **引数**: 挿入元の有効な半開区間 `[first, last)`、またはキーと値の組のリスト `values`。範囲の要素は単一要素の `insert` に渡せること。
- **戻り値**: なし。
- **内容**: 先頭から順に挿入し、重複キーの既存値は変更しない。空の範囲・リストなら何もしない。初期化リスト版には値のコピー構築が必要。
- **計算量**: K要素に対して期待償却 `O(K)`。再構築がある呼び出しは期待 `O(K + C + C')`。
- **無効化**: 単一要素の挿入と同じ。挿入元の範囲が挿入先自身を参照する場合は、途中の操作でイテレータを無効にしないこと。

### try_emplace

書式: `template<class... Args> std::pair<iterator, bool> try_emplace(key_type key, Args&&... args)`。

- **引数**: キー `key` と、値を構築するための引数列 `args...`。値がその引数列から構築可能であること。
- **戻り値**: 対応する要素のイテレータと、新規挿入できたかの組。
- **内容**: 未登録なら `args...` を転送して値を構築する。登録済みなら値を構築せず、既存値を変更しない。渡した引数の評価自体は通常の関数呼び出しと同様に行われる。
- **計算量**: 期待償却 `O(1)`。再構築する回は期待 `O(C + C')`。
- **無効化**: 新規挿入の再構築時は全要素への参照・ポインタ・イテレータが無効。それ以外では既存要素は無効にならない。
- **補足**: 再構築が必要な場合は、引数が既存要素を参照していても使えるよう、新しい値を先に構築してから再構築する。

### erase（キー指定）

書式: `size_type erase(key_type key)`。

- **引数**: 削除するキー `key`。
- **戻り値**: 登録済みなら1、未登録なら0。
- **内容**: 対応する要素を破棄する。容量を変更せず、他の有効な要素も移動しない。
- **計算量**: 期待償却 `O(1)`、最悪 `O(C)`。一度の削除で複数の削除跡を回収する場合がある。
- **無効化**: 削除した要素への参照・ポインタ・イテレータだけが無効。

### erase（イテレータ指定）

書式: `iterator erase(iterator position)`、`iterator erase(const_iterator position)`。

- **引数**: このマップの有効な要素を指す `position`。`end()` や他のマップのイテレータは渡せない。
- **戻り値**: 削除した要素の次の要素のイテレータ。次がなければ `end()`。
- **内容**: 指定要素を破棄する。容量を変更せず、他の有効な要素も移動しない。`it = m.erase(it)` で走査中に削除できる。
- **計算量**: `O(1 + D + W)`。Dは回収する削除跡の数、Wは次の要素までに調べる64スロット単位の管理領域の数。最悪 `O(C)`。先頭から順に全削除する場合、走査を含む合計は `O(N + C)`。
- **無効化**: 削除した要素への参照・ポインタ・イテレータだけが無効。

### begin・end・cbegin・cend

書式: `iterator begin() noexcept`、`const_iterator begin() const noexcept`、
`const_iterator cbegin() const noexcept`、`iterator end() noexcept`、
`const_iterator end() const noexcept`、`const_iterator cend() const noexcept`。

- **引数**: なし。
- **戻り値**: `begin/cbegin` は最初の要素、空なら終端。`end/cend` は終端。const版と `cbegin/cend` は `const_iterator`。
- **内容**: 範囲forやイテレータ走査に使う。走査順序は未規定で、シードや再構築によって変わる。終端は参照外し・インクリメントできない。
- **計算量**: `begin/cbegin` は最悪 `O(1 + C/64)`。`end/cend` は `O(1)`。全走査は `O(N + C/64)`。

### イテレータ操作

`iterator` / `const_iterator` は前方イテレータ。デフォルト構築・コピー・代入に対応し、
`iterator` から `const_iterator` へ変換できる。逆方向の変換には対応しない。

| 操作 | 引数・前提 | 戻り値・内容 | 時間計算量 |
|---|---|---|---|
| デフォルト構築 | 引数なし | どのマップにも属さないイテレータ。参照外し・インクリメント・削除には使えない | `O(1)` |
| コピー・代入・const版への変換 | 元のイテレータ | 同じ位置を指すイテレータ。代入は自分への参照を返す | `O(1)` |
| `*it` | 有効な要素を指すこと | 要素への参照 | `O(1)` |
| `it->` | 有効な要素を指すこと | 要素へのポインタ | `O(1)` |
| `++it` | 有効な要素を指すこと | 次の要素または終端へ進み、自分への参照を返す | `O(1 + W)`、最悪 `O(1 + C/64)` |
| `it++` | 有効な要素を指すこと | 次へ進み、変更前のイテレータのコピーを返す | `++it` と同じ |
| `a == b` / `a != b` | 比較するイテレータ | 所属マップと位置が一致するか / 一致しないか。const版との比較も可能 | `O(1)` |

Wは次の要素までに調べる64スロット単位の管理領域の数。
各操作の追加領域は `O(1)`。`--`、加減算、添字アクセスには対応しない。
再構築で全イテレータが無効になる。swap・ムーブをまたいだ保持には対応しない。

### at

書式: `mapped_type& at(key_type key)`、`const mapped_type& at(key_type key) const`。

- **引数**: 取得するキー `key`。
- **戻り値**: 対応する値への参照。constなマップではconst参照。
- **内容**: 登録済みの値を取得する。未登録なら `std::out_of_range` を送出し、挿入は行わない。値のデフォルト構築は不要。
- **計算量**: 期待 `O(1)`、最悪 `O(C)`。

### size・empty

書式: `size_type size() const noexcept`、`bool empty() const noexcept`。

- **引数**: なし。
- **戻り値**: `size` は要素数、`empty` は要素数が0ならtrue。
- **内容**: 容量や削除跡を含めず、現在の有効な要素だけを数える。
- **計算量**: いずれも `O(1)`。

### clear

書式: `void clear() noexcept`。

- **引数・戻り値**: なし。
- **内容**: 全要素を破棄して要素数を0にする。確保容量とシードは保持する。容量も解放する場合は、その後に `rehash(0)` を呼ぶ。
- **計算量**: `O(C)`。要素が少なくても確保容量に比例する。
- **無効化**: 全要素への参照・ポインタ・イテレータが無効。

### reserve

書式: `void reserve(size_type elements)`。

- **引数**: 格納したい要素数 `elements`。追加する件数ではなく、合計要素数。
- **戻り値**: なし。
- **内容**: 使用率50%以下で指定件数を格納できる容量まで拡張する。現在の容量で十分なら何もしない。縮小・削除跡だけの整理は行わず、`reserve(0)` も何もしない。
- **計算量**: 拡張時は期待時間 `O(C + C')`、追加領域 `O(C')`。拡張なしは時間 `O(log(elements + 1))`、追加領域 `O(1)`。引数0なら `O(1)`。
- **無効化**: 拡張した場合のみ、全要素への参照・ポインタ・イテレータが無効。
- **注意**: 予約後も、削除と挿入を繰り返した場合は削除跡の整理で再構築することがある。指定容量が確保上限を超えると `std::length_error`、領域確保に失敗すると `std::bad_alloc`。

### rehash

書式: `void rehash(size_type buckets)`。

- **引数**: 再構築後のスロット数の下限 `buckets`。要素数の指定ではない。
- **戻り値**: なし。
- **内容**: 指定数以上、かつ現在のN要素を使用率50%以下で保持できる容量に再構築する。容量は16以上の2のべき乗へ切り上げる。同じ容量でも再構築し、削除跡を除去する。シードは変わらない。
- **計算量**: 期待時間 `O(C + C')`、追加領域 `O(C')`。再構築中は旧・新の領域を両方保持する。
- **無効化**: 全要素への参照・ポインタ・イテレータが無効。
- **補足**: `rehash(0)` は現在の要素数に必要な最小容量まで縮小する。空なら領域を解放して容量0にする。この解放処理は時間 `O(C)`、追加領域 `O(1)`。
- **注意**: 確保上限超過は `std::length_error`、領域確保失敗は `std::bad_alloc`。値がコピーできずムーブが例外を投げる型では、再構築失敗時に既存値の一部がムーブ済みになる場合がある。この注意は挿入・reserveによる再構築にも当てはまる。

### bucket_count・load_factor・max_load_factor

書式: `size_type bucket_count() const noexcept`、`float load_factor() const noexcept`、
`float max_load_factor() const noexcept`。

- **引数**: なし。
- **戻り値**: `bucket_count` はスロット数C。`load_factor` は `N / C`（容量0なら0）。`max_load_factor` は常に `0.5F`。
- **内容**: 現在の容量・使用率・最大使用率を取得する。使用率に削除跡は含めない。最大使用率を変更するオーバーロードはない。
- **計算量**: いずれも `O(1)`。

### hash_seed

書式: `std::uint64_t hash_seed() const noexcept`。

- **引数**: なし。
- **戻り値**: 現在のハッシュシード。
- **内容**: 不具合の再現時などに、`cp::hashmap<long long, int> replay(0, m.hash_seed());` で再利用できる。シードは再構築・clearで変わらず、コピー・ムーブで引き継がれ、swapでは交換される。
- **計算量**: `O(1)`。

### dump・operator<<

書式: `std::ostream& dump(std::ostream& out = std::cerr) const`、
`std::ostream& operator<<(std::ostream& out, const hashmap& map)`。

- **引数**: 出力先ストリーム `out`。`dump` では省略可能。`operator<<` の `map` は出力するマップ。
- **戻り値**: 出力先ストリームへの参照。
- **内容**: 現在の全要素を `{key: value, ...}` の形式で出力する。空なら `{}`。改行は付けない。順序は走査順序と同じで未規定。値がストリーム出力可能であること。マップを変更しない。
- **計算量**: 出力処理のコストをLとして時間 `O(N + C/64 + L)`、マップ側の追加領域 `O(1)`。
